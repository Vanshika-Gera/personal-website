# Vanshika's Personal Website

This is my personal website that I created as part of the Stardance mission.

I made this website while learning the basics of **HTML and CSS**. I wanted to keep it simple but still make it look clean and personal.

## About the Website

The website includes:

* A navigation bar
* Home section
* About Me section
* Projects section
* Blog section
* Silly Stuff section
* Contact form
* Images
* Responsive design for smaller screens

## Technologies Used

* HTML
* CSS

## What I Learned

While making this website, I learned how to:

* Create the basic structure of a webpage using HTML
* Add images and links
* Create navigation bars
* Style webpages using CSS
* Use Flexbox and Grid
* Create cards and different sections
* Make a website responsive
